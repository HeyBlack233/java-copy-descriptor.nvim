### Highlights

### Details

- Added method, constructor, overload, interface, dependency, array, varargs,
  generic, and nested-type descriptor support.
- Added clipboard verification and English error notifications.
- Added Vim help, configuration, and a headless test suite.
- Documented the `ft = 'java'` lazy-loading requirement so JDT LS does not
  start for non-Java buffers.
